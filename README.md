## How I Think About AI PM Work

I believe AI PMs should be able to connect four layers:

1. **Business scenarios** — understand the real workflow, pain point, and user decision process.
2. **Knowledge structure** — define the objects, relationships, rules, and context behind the workflow.
3. **Agent workflow** — design how AI agents reason, call tools, use data, and involve humans.
4. **Prototype validation** — build or vibe-code demos to make ideas testable and easier to communicate.

This profile is my attempt to make that process visible through public projects.
