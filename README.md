I work on enterprise agent products in advanced manufacturing. My public projects let me test how data models, rules, evidence, and human review fit together.

## Selected projects

**[Prompt-to-Ontology](https://github.com/wenhaoyu-bryan/Prompt-to-Ontology)** — A runnable Pet Food reference that turns structured data into typed graph objects, evaluates rules with explicit evidence, and routes agent suggestions through human review. [Read the project walkthrough →](https://wenhaoyu-bryan.github.io/projects/prompt-to-ontology/)

**[Agent Anatomy](https://github.com/wenhaoyu-bryan/agent-anatomy)** — Five interactive visual essays that replay an agent's loop, failure modes, web retrieval, memory, and teamwork using one open trace format. [Explore the interactive site →](https://wenhaoyu-bryan.github.io/agent-anatomy/)
